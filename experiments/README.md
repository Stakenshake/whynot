# Experiments

Each folder is one experiment. Results are written up in
[`../docs/findings.md`](../docs/findings.md) with links to the detailed pages.

```
e0/   judge calibration      can a model reliably score "recommends vs excludes"?
e1/   code context           does real code weaken a decision's influence?
e2/   false obedience        does an irrelevant decision distort unrelated work?
e3/   statistical power      the two main claims at n=20 across three families
e4/   dose-response          does the age of a decision matter?
e5/   real agent             does Codex use it across real sessions?
      fixture/               generated by e1/build-fixture.mjs; not committed
legacy/                      the first-pass scripts, superseded, kept for repro
lib/codex.mjs                shared Codex CLI locator
```

## Running

All scripts talk to an OpenAI-compatible endpoint. Point `MAGPIE_URL` at yours
(the default is `http://127.0.0.1:3425/v1/chat/completions`).

```bash
node experiments/e0/judge.mjs          # 186 judge calls
node experiments/e1/build-fixture.mjs  # generate the fixture repo
node experiments/e1/run.mjs            # 96 generation + 96 judge calls
node experiments/e2/run.mjs            # 90 calls
node experiments/e2/run-b.mjs          # 48 calls
node experiments/e3/run.mjs            # 240 calls
node experiments/e4/run.mjs            # 168 calls
node experiments/e4/rejudge.mjs        # re-score saved responses
node experiments/e5/run.mjs            # real Codex sessions (needs the fixture)
```

Raw model responses go to `<experiment>/out/` and are gitignored. To reproduce
a number, run the script; to check a judgement, read the saved response.

## Conventions

Every script follows the same rules, learned from failures recorded in
[`../docs/preregistration.md`](../docs/preregistration.md):

1. **An error is never a data point.** Judging failures are excluded from
   denominators and reported. `e4/rejudge.mjs` exists because the first pass
   broke this rule and turned a judging outage into a clean-looking 0/12.
2. **Assert the input.** `e3` aborts if the injected context does not contain
   the decision's title; the first run silently injected "nothing found" because
   the query did not match.
3. **Assert the output.** A tool that fails to start produces no events and a
   clean exit code — indistinguishable from success unless you check. `e5`
   fails fast if the Codex CLI cannot be found.

## legacy/

The first pass at E1/E2/E4 used a different structure. Those scripts are kept
because their results are cited (the prompt-warning failure, the original Codex
integration), but the current versions are in `e3/`, `e4/`, and `e5/`.

| File | Was | Superseded by |
|---|---|---|
| `exp1-exp4.mjs` | original Redis + TypeScript experiments | `e3/` |
| `judge-v1.mjs` | first judge pass | `e0/judge.mjs` |
| `prompt-warning.mjs` | the "be skeptical of old notes" test | kept as evidence — it failed |
| `expiry.mjs` | first expiry test | `e4/` |
| `codex-integration.mjs` | first real-agent test | `e5/` |
| `probe.mjs` | gateway connectivity check | still useful |
